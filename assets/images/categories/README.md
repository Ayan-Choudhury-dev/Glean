# Category artwork

The PNGs in this folder are 3D object renders from
[The Thiings Collection](https://www.thiings.co/things), which publishes
free-to-use AI-generated 3D icons.

- Downloaded from `https://lftz25oez4aqbxpq.public.blob.vercel-storage.com/image-<fileId>.png`
- Downscaled to 128px (`sips -Z 128`)
- Mapped to inventory categories in `constants/categoryImages.ts`

If you swap any of these, keep the same filenames or update the map.
